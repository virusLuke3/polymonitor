# Protomaps v4 sprites

Unmodified `dark` and `light` sprite atlases from [protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets/tree/028c18f713baecad011301ff7a69acc39bcc2ae7/sprites/v4), commit `028c18f713baecad011301ff7a69acc39bcc2ae7`. Both 1x and 2x assets are included. Sprites derive from MIT-licensed [tangrams/icons](https://github.com/tangrams/icons); see LICENSE.txt.

Served from the application origin so an external sprite request cannot block basemap tiles. Verified byte-for-byte against the previously used GitHub Pages URLs on 2026-10-03. Update all atlas JSON/PNG pairs together.
